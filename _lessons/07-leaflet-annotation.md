# Lesson 7: Using an Allmaps Annotation in Leaflet

Before starting, make sure you have completed [Lesson 4: Command Line Setup]({{ '/lessons/command-line-setup/' | relative_url }}) or already have the required tools installed.


This lesson will adapt the Leaflet workflow from `../ph-allmaps/part-3/03_leaflet.md`.

The goal is to use the Allmaps Leaflet plugin to add a georeferenced historical map as an overlay in a Leaflet web map.

## Source Lesson

- PH draft: `../ph-allmaps/part-3/03_leaflet.md`
- Demo folder: `../ph-allmaps/part-3/allmaps-leaflet-demo/`

## Planned Structure

1. Copy or open the starter template
2. Review `index.html`
3. Review `style.css`
4. Review `script.js`
5. Add the base map
6. Add the Allmaps annotation layer
7. Add the layer control
8. Preview the final map

## Setup Note

This page should become a light web-mapping lesson, not another general CLI lesson.
The Allmaps annotation is the bridge between the georeferencing work and the Leaflet overlay.
